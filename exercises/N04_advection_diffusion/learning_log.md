# N04 学習ログ

## モデルの選択と予想

- SELECTED_MODEL（linear / nonlinear）：linear
- 選択理由、連続式と離散式、u・D・周期積分の意味（すべて無次元）：
選択理由：最初はできるだけシンプルに考えたかったので，linearを選んだ．
連続式：\frac{\partial u}{\partial t}+\frac{\partial f(u)}{\partial x}=D\frac{\partial^2 u}{\partial x^2},\\
離散式：u_i^{n+1}=u_i^n-\frac{\Delta t}{\Delta x}\bigl(f(u_i^n)-f(u_{i_-}^n)\bigr)+\frac{D\Delta t}{\Delta x^2}(u_{i_+}^n-2u_i^n+u_{i_-}^n)
u：有限な実数スカラー
D：拡散係数
周期積分：特定の周期をもつ関数の積分を計算する方法

- 同じ初期値・格子・時刻・刻みの3条件で予想する違い：
移流だけでは分布が移動し，拡散だけでは分布がなめらかになり，両方あると移動しながらなめらかになると予想する．

## 式・実装・テストの対応

- 選択流束、周期左右隣接、同じ旧配列を使う合成更新：
線形を選んだので，流束は `speed * u` とした．
配列の端では反対側の端を隣として計算した．
新しい値は，更新前の値を使って計算した．

- CFL＋2Fo，safety，実効刻み，個別上限のminでは不足する理由：
移流と拡散の両方を計算するので，両方を合わせて時間刻みを決める必要がある．
safetyを掛けて，時間刻みを少し小さくした．

- 必須4群の期待値と検出する誤り：
1. 非対称な配列を1ステップ更新し，計算結果が期待値と合うこと，古い配列が変わらないことを確認した．流束差や周期端の扱いの間違いを見つける．
2. 定数の配列を更新して値が変わらないことを確認した．また，周期積分の計算結果も確認した．
3. 移流なしの場合と拡散なしの場合を確認し，それぞれの更新結果が期待値と合うことを確かめた．
4. 合成条件から求めた時間刻み，最終時刻まで進むこと，安定条件を超えないこと，計算結果が有限であることを確認した．

- 自作保存テストの入力、初期積分、反復回数、許容誤差の根拠：
入力：8点の非対称な初期配列
初期積分：領域の長さを2としたので，格子幅は2÷8＝0.25，初期積分は0.25×配列の合計＝2.075
反復回数：時間刻み0.005で20回
許容誤差の根拠：許容誤差は1e-12とした．これは計算中の小さな丸め誤差を許しつ，積分値が目立って変わる誤りを見つけるためである．

- 自作収束テストの解析解、40・80・160点の誤差、次数、許容範囲の根拠：
滑らかな初期条件(:mode)を使い，最終時刻を1.0にそろえて40・80・160点で計算した．数値解と解析解の各点の差からRMS誤差を計算した．格子を細かくしたときに誤差が減る割合を観測次数で調べ，40点から80点，80点から160点の両方で0.8〜1.2に入ることを確認する．

- 各テストで検出できる誤りと限界：
保存テスト：複数回更新したときに周期積分がずれる誤りを見つけられる．
収束テスト：今回の線形モデルと滑らかな初期条件で，格子を細かくしたときの誤差の減り方を確認できる．
ただし、これらのテストだけでは、すべての初期条件や別のモデル・パラメータで正しく動くことまでは確認できない．
